Why it exists

Most AI writing tools produce the same hollow post.

LinkedIn’s native editor strips the formatting that makes a post scannable, and every “write me a post” tool reaches for the same tired phrases. grip-post does the opposite of both: it gives you the formatting LinkedIn won’t, and it stands between you and the words that make readers stop trusting you. The refusal is the product.

How it works

Three filters, all running on your machine.

Nothing is sent anywhere. The free tier runs every check locally with no network calls and no telemetry.

01 / FORMAT

Unicode that survives paste

Seven transforms map plain text to real Unicode characters, so the styling holds when you paste into LinkedIn: bold, italic, corner brackets ⌜ X ⌟, a heavy rule ━━━, an arrow bullet ▸ ─→, middle-dot handle lists A · B, and a diamond terminator ◆.

02 / REFUSE

Anti-fluff gate

Flags 25 hard-coded LinkedIn-cringe phrases — “revolutionary”, “thrilled to announce”, “paradigm shift”, “synergy” — plus em-dash and emoji density warnings. The list lives in source: changing it needs a pull request and a passing test. strip-tells goes further and removes rocket-emoji openers and “Thoughts?” closers, showing you exactly what it cut.

03 / GROUND

Unsourced-claim check

A regex pass flags claims that need a source — “studies show” with no citation, a bare percentage, “everyone knows” — so you can add a link or soften the wording before a critic does it for you in the comments.

Real commands

It works in your terminal too.

The Claude Code plugin and the Chrome side panel share one core library, so every transform works in both. These commands actually run. 

$ /grip-post:grip-post check  We are thrilled to announce
DENY: "thrilled to announce" (banned phrase)

$ /grip-post:grip-post bold   Hiring three engineers
𝗛𝗶𝗿𝗶𝗻𝗴 𝘁𝗵𝗿𝗲𝗲 𝗲𝗻𝗴𝗶𝗻𝗲𝗲𝗿𝘀   (survives LinkedIn paste)

$ /grip-post:grip-post italic a quiet aside
𝘢 𝘲𝘶𝘪𝘦𝘵 𝘢𝘴𝘪𝘥𝘦

$ npx tsx bin/grip-post.ts strip-tells --file draft.txt
Stripped 2 tell(s): leading rocket emoji, trailing "Thoughts?"

No plugin system? Run the CLI directly: npx tsx bin/grip-post.ts check --file draft.txt. Requires Node ≥ 20.

One core, two front-ends

Browser side panel or terminal — same behaviour.

The Chrome extension and the Claude Code plugin are two thin surfaces over the exact same pure core library. Add a transform once and it appears in both, with no second copy to drift out of sync.

The honest part

What it does and doesn’t do.

On your device only

Drafts, stats and licence keys live in chrome.storage.local — never synced, never uploaded.

LinkedIn only

The extension can reach https://www.linkedin.com/* and nowhere else. Chrome blocks any other network call regardless of code.

No magic words

The gate is plain regex over a list you can read in the source. No model decides what counts as fluff — a reviewed list does.
