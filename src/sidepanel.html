These are Unicode characters, not real formatting — LinkedIn has no bold button, so a "bold" letter is a different character that happens to look bold. It pastes as plain text anywhere. The trade-off is real: screen readers cannot read styled letters, LinkedIn's search will not match them, and a few older fonts show empty boxes instead. Style a phrase, not a post.
